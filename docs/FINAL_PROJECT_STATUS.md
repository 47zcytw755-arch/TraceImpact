## Known Limitations (Documented)

1. **Synthetic Dataset:** Core nonprofit data is synthetic (generated by Faker). Clearly labeled.
2. **World Bank API Dependency:** Real-time ingestion requires network access to api.worldbank.org.
3. **PostgreSQL Required:** Platform requires a running PostgreSQL 16+ instance.
4. **ML Non-Causality:** Anomaly detection identifies statistical outliers only — no causal claims.
5. **Single-User:** Dashboard does not implement multi-user authentication.
