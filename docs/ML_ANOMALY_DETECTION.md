# Machine Learning Anomaly Detection Architecture — TraceImpact 2.0

## 1. Overview & Objective

TraceImpact 2.0 integrates unsupervised machine learning directly into its real public data pipeline. The goal is to detect statistically unusual observations in global macroeconomic and social indicators from the World Bank API without requiring human analysts to inspect thousands of country-year time series manually.

```
+-------------------------------------------------------------------------+
|                  WORLD BANK MACROECONOMIC OBSERVATIONS                  |
|                 (5,588 Country-Year Indicator Records)                  |
+-------------------------------------------------------------------------+
                                     |
                                     v
+-------------------------------------------------------------------------+
|                     FEATURE EXTRACTION ENGINE                           |
|  - Multi-year Country Historical Mean, Std Dev, Z-Score                |
|  - Consecutive Year-over-Year (YoY) Growth % Rate                      |
|  - Cross-Country Peer Group Mean & Cross-Sectional Z-Score             |
|  - Ratio to Historical Baseline                                         |
+-------------------------------------------------------------------------+
                                     |
                                     v
+-------------------------------------------------------------------------+
|                ISOLATION FOREST ANOMALY DETECTOR                        |
|  - Algorithm: sklearn.ensemble.IsolationForest                          |
|  - Baseline Contamination: 4.0% (Configurable)                         |
|  - Ensembles: 100 Isolation Trees, Random State = 42                   |
|  - Model Versioning & Hyperparameter Registry: ml_anomaly_models        |
+-------------------------------------------------------------------------+
                                     |
                                     v
+-------------------------------------------------------------------------+
|                      POSTGRESQL PERSISTENCE                             |
|  - Table: world_bank_anomalies (Score, Flag, Feature Snapshot JSONB)   |
|  - Idempotent Upsert: ON CONFLICT (observation_id, model_version)      |
+-------------------------------------------------------------------------+
```

---

## 2. Fundamental Methodological Boundary: Non-Causality Notice

> ### ⚠️ STRICT NON-CAUSALITY NOTICE
> **Anomaly detection in TraceImpact 2.0 is descriptive, not causal.**  
> An anomaly score generated by the Isolation Forest model indicates that an observation deviates significantly from historical trends and peer distributions according to the extracted feature set.
>
> **The model DOES NOT establish:**
> - Why the anomaly occurred (causality).
> - Which policy, government intervention, or crisis caused the deviation.
> - Whether the reported number reflects physical reality, a reporting methodology revision, or a currency devaluation artifact.
>
> TraceImpact strictly labels all contextual explanations as **interpretative hypotheses** and requires human domain verification.

## 3. Feature Engineering

For each verified observation `(country_code, indicator_code, year, indicator_value)` in `world_bank_observations`, the `WorldBankFeatureExtractor` derives 4 primary statistical features:

| Feature Name | Mathematical Definition | Domain Significance |
| :--- | :--- | :--- |
| `z_score` | $\frac{V_{c,i,t} - \mu_{c,i}}{\sigma_{c,i} + \epsilon}$ | Measures standard deviations from the country's own multi-year trajectory. |
| `yoy_growth_pct` | $\frac{V_{c,i,t} - V_{c,i,t-1}}{|V_{c,i,t-1}|} \times 100$ | Captures sudden, high-velocity single-year accelerations or contractions. |
| `peer_z_score` | $\frac{V_{c,i,t} - \mu_{global,i,t}}{\sigma_{global,i,t} + \epsilon}$ | Measures deviation relative to global peers in the exact same reporting year. |
| `hist_ratio` | $\frac{V_{c,i,t}}{\mu_{c,i} + \epsilon}$ | Relative scaling factor against long-term historical baseline. |

### Feature Snapshot
Every persisted anomaly includes an immutable JSONB feature snapshot:
```json
{
  "historical_mean": 46.47,
  "historical_std": 9.32,
  "z_score": -1.60,
  "yoy_growth_pct": -39.71,
  "peer_mean": 71.25,
  "peer_z_score": -3.81,
  "hist_ratio": 0.678
}
```

## 4. Model Lifecycle & Versioning

To avoid unstable model drift and unpredictable behavior in production, TraceImpact 2.0 adheres to a controlled model lifecycle:

1. **Controlled Training**: Models are not blindly retrained on every single HTTP batch. Training is triggered on demand, upon major historical data refreshes, or when baseline drift criteria are met.
2. **Model Registry (`ml_anomaly_models`)**: Every trained model is registered in PostgreSQL with:
   - `model_name`: e.g. `IsolationForest_WorldBank`
   - `model_version`: Semantic version string, e.g. `v1.0.0`
   - `hyperparameters`: Serialized JSONB (`n_estimators`, `contamination`, `random_state`)
   - `metrics_summary`: Baseline distribution, score range, flagged count.
3. **Artifact Persistence**: Fitted model weights are serialized to disk (`models/IsolationForest_WorldBank_v1.0.0.joblib`) for sub-millisecond inference reuse.
4. **Idempotent Ingestion Hook**: Newly ingested data is scored using the active registered model; anomalies are persisted to `world_bank_anomalies` via `ON CONFLICT (observation_id, model_version) DO UPDATE`.
